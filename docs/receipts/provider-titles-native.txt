Behavior
The latest retained Claude ai-title is preferred in History without a role filter.
The index supplies only a record locator; retained raw bytes, predecessor,
context, repository/session scope and typed metadata determine the displayed
excerpt. Malformed, empty, ambiguous or later unreadable records use the existing
eligible-request/neutral fallback. Ordinary later unsupported events do not
hide a valid recorded title. The title text never becomes a human request,
capture identity or attribution. The per-page raw/predecessor budget is 8 MiB;
fallback inspects at most four request candidates per capture.

Parser projection becomes providers-v5-utc-context-relay-title. The additive
partial index changes no raw ownership or schema number. Explicit retained-raw
rebuild restores title locators in old captures after original source loss.
Old projection versions cannot be reused for append context. The migration test
simulates v4 rows/seal; it is not an execution of an old application binary.
