Scope and evidence boundary
All maintained archive decode/capture/verification/export logic and these native tests are Bend 2. The existing narrow SQLite C bridge is unchanged. These are isolated synthetic backend executables, not the merged application or an observed GUI session. No full repository-suite or Lean/kernel verdict is claimed here; Lean is not an application runtime dependency.

Receipt audit: read each successful receipt and native log, recounted its literal "PASS " lines, compared archived before/after input manifests, and independently SHA256-hashed the stored executable. All ten entries below have native exit 0, matching recorded hashes, and unchanged before/after input manifests. Toolchain checksum checks before and after each gate also exited 0. Manifest input counts include support/toolchain files, not only Bend modules.

Counts below are emitted PASS lines (assertion groups and synthetic setup checks), not unique test cases or a count of every Boolean assertion. Several suites overlap; do not add them into a unique-test total. Schema fence and compatibility
Schema 3 owns compressed-container evidence independently from decompressed logical source bytes; existing plain generations keep identity encoding, IDs and raw bytes. The atomic gate actually launched the pre-schema-3 executable (SHA256 78c396eb02c15fed7d4c3266185244ffe851d7333872042090d9bb14cbb66935), observed startup refusal of a schema-3 library, and verified unchanged typed tables, pinned evidence and SQLite integrity. This is a startup fence, not protection from an already-running old executable/connection. Final path revalidation compares canonical source bytes; changes after its final comparison are outside the observed interval.

Bounded profile and physical Mac resource receipt
Admitted profile: at most 1 MiB compressed input, 4 MiB logical output, 8 MiB advertised window, 64 frames, 4,096 blocks per frame, and 16 retained container chunks of at most 64 KiB. Dictionary frames are refused. This is bounded archive support, not unrestricted archive parity.

The limits gate's archived executable is Mach-O arm64, and native-resource.json records Darwin wait4 accounting. The handoff records execution on the physical Apple Silicon Mac with Tart stopped and no concurrent compiler. These are single fixture trials, not latency percentiles, typical session throughput, VM results or a Swift comparison.
