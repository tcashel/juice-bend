  commits or rolls back a caller transaction. Owned failures roll back; cleanup

- Save validates existing state, writes the complete pair with bound SQL,
  verifies both present typed keys and exact values, then commits. Native tests
  cover a partial statement failure, ignored update, deferred commit failure,
  read-only refusal, competing writer, persistence and reopening.

  ignored insert. The correction requires both exact keys after writing. Three
  actual SQLite IGNORE-on-INSERT regressions cover both default keys missing,
  missing enabled=true while interval changes, and missing interval=30 while
  enabled changes. Each refuses success and preserves the original key set and
  other preference. Independent re-review confirmed this defect was closed.
- Scheduling uses exact Nat milliseconds, preserves uptime above U32, returns
  no deadline when disabled, and rejects addition beyond the pinned native
  2^48-1 limit before arithmetic can overflow.
